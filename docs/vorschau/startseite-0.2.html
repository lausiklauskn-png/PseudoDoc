Was möchtest du mit deiner Datei tun?

1

Rein

Kann ich das öffnen?

  • versteckter Text, Anweisungen an eine KI
  • Makros, getarnte Programme
  • fremde Links, Absender passt nicht
2

Zur KI

Kann ich das einer KI zeigen?

  • Namen und Nummern werden zu ⟦NAME-1⟧ …
  • Bilder schwarz abdecken
  • Antwort kommt mit echten Angaben zurück
3

Raus

Kann ich das weitergeben?

  • Schlüssel, IBAN, Mailadressen gefunden?
  • Ort im Foto, Autor, Kommentare
  • bereinigte Kopie, Original bleibt
